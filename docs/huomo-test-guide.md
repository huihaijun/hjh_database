# 火魔副本测试交接

实现依据：完整机制、十项喊话修订及2026-09-12的十三项机制调整。建筑是魔王身体，烈焰人核心承伤；不是移动实体 Boss。

## 进入与退出

- 世界默认 `world`，配置 `plugins/hjh_database/dungeon/huomo.yml`，首次加载从 JAR 生成。
- 入口石按钮 `(1150,23,924)`；集结区域为 X=1146～1154、Z=919～923 的地面上，脚部 Y=23～23.6。
- 全队 1～5 人、等级至少 40、稀有度总和至少 42。任何一人不合格，整队不进入。场地全服单局占用。
- 入场 `(1089,15,894)`，面向南侧，`status=5`，tag=`huomo_player`。
- 胜利出口 `(1154.30,57.00,891.09)`，yaw=262.24（等价982.24），pitch=7.65；胜利 `status=3`。
- 死亡仅淘汰该玩家，走原有奈何桥流程；退服处决该玩家，队友继续。服务器异常退出的未结算参与者重新登录时处理失败；已判定胜利但尚未成功传出的玩家重新登录时补传奖励房。
- 目前只有测试难度，不产出正式奖励。临时道具只回收带 `huomo_temporary` PDC 的本副本物品，保留玩家自带装备。

## 核心和炉温

- 四个核心点严格使用审批坐标，不叠加半格偏移。HP=15000，护甲=100，禁止移动/AI攻击/击退，持续发光。
- 每下降8%最大生命，先无敌并凝聚红色粒子1秒，再向北炸飞半径6格内玩家，基础物理伤害15，然后随机换至另一个核心点，炉温降低5%。回血不重复触发已通过的血线。BossBar只显示名称、血条进度及泄压状态，不显示具体血量；核心无敌时血条蓝色，可受伤时红色。
- 70%、35%、10%阶段只向前；非致命大额伤害跨过多个血线时顺序执行转阶段。转阶段优先于待执行的核心换位，打断原主动技能，期间核心免伤；已经留下的地火继续存在。
- 炉温初始0%，战斗开始后每分钟+20%；有效核心伤害+1%，全局CD3秒。泄压期间受击不升温。
- 40%护甲乘0.8，80%移速乘0.8；降温即时解除对应门槛效果，不影响其他属性来源。
- 每满10%炉温主动CD-1秒（最低6秒），不足一档不减少，例如15%仅减少1秒。每5%刷怪CD-2秒（下限40/35/30/20/15秒），技能伤害加算5%。满温技能倍率2倍，小怪普攻和身体堵血管伤害不加成。
- 前三个阶段各最多一次满温恢复3000HP（不溢出最大生命）；进入最终血线后不再回血，包括转阶段预警期间。重复满温仍会触发喷柱：每3秒10处半径5格喷柱，预警1秒、喷射1秒、高8格，基础30物理伤害；一轮每个玩家最多中一次，避难所不抵挡。
- 两次焚炉压缩及焚世万物各扣最多30个百分点炉温，不足也能释放。低于100%立即撤销喷柱及待喷预警。

## 技能与时间轴

| 阶段 | 循环顺序 | 完成后基础CD |
| --- | --- | --- |
| >70% | 焚息、普通火印三连 | 15秒 |
| 35%～70% | 炽焰锁、加强火印五连、吞火 | 15秒 |
| 10%～35% | 加强火印一轮、血脉；加强火印两轮、血脉；加强火印三轮、血脉……每轮仍为五连 | 15秒 |
| ≤10% | 焚息、加强火印五连、吞火 | 10秒 |

- 焚息：4秒预警，5格高火墙从Z=907向北扫至Z=872，共10秒。南侧Z>907躲避；实际碰撞箱接触结算50物理伤害，每人CD2秒。避难所可挡。完整释放后进入5秒§b[泄压]：期间累计每造成300点实际伤害，炉温降低3%，单次最多9%；即便达到上限，期间受击仍不升温。自然升温继续。被转阶段打断不触发泄压。
- 泄压喊话：`§7火焰魔王释放大量魔焰后,核心暂时进入了§b[泄压]§7状态！`；`§6趁现在攻击核心可以降低§c炉温§6！`
- 火印：普通跟踪5秒，加强跟踪3秒，全程BossBar预警。随后固定XZ，以稍快于玩家自由落体的速度落至地面；爆炸45物理、半径6格，留30秒半径4格地火，附带参考红翎弩的营火烟雾粒子，每秒10物理，同一秒重叠地火不重复结算。爆炸后立即选下一名玩家，优先本轮未选过的玩家。避难所只抵挡爆炸。
- 炽焰锁：预警开始时选人并向全队点名，预警3秒后连接该玩家5秒，每秒一次，基础伤害按Z=873～919由30线性降低到3。目标死亡或离场时不偷偷换人。
- 吞火（原稿“吞日”为笔误）：地火变为HP150、护甲0、静止可攻击火种，保留8秒预警，随后在原地等待10秒，以末地烛亮粒子提示吸收倒计时，时间到直接消失视作吸收。1～5名实时玩家对应火种上限3/4/5/无上限/无上限；人数减少时移除超额火种，不算击杀或吸收。每杀死一颗炉温降低3%；每颗被吸收仍+5%炉温、全体15基础物理。
- 焚炉压缩：两次均预警3秒，基础50物理、50%穿甲。起跳窗口为预警结束前后0.5秒，即本次施法开始后的2.5～3.5秒；判定保留后0.5秒输入容差。避难所可挡。
- 焚世万物：预警5秒，基础80物理、50%穿甲，仅避难所抵挡，跳跃无效。
- 所有主动技能结束后才开始CD；被动刷怪独立运行。火印持续地火不占用主动CD。

## 避难所、血管与刷怪

- 两个避难所各3次，按实际顶盖下方判断保护。第三次仍成功抵挡；同次攻击保护多人只耗一次，每次成功抵挡炉温降低5%，火印每颗爆炸分别计算。进入时以ActionBar提示“你已进入残骸保护区，当前残骸可抵挡次数：X/3”，停留时刷新，次数变化同步，离开及结算时清除。
- 随损耗分三批替换红色蘑菇方块；三次之后不再抵挡。精确方块掩码来自 `huomo.schem`，不会填充原有空气。
- 七条血管共121个坐标，长度依次16/15/17/18/16/19/20；顺序保存在 `dungeon/huomo/veins.csv`。
- 血脉预警6秒，清除旧怪物（保留核心，清场不算尸体）。开始及后续波次只刷近卫，按实时1～5人刷5/6/6/7/8只，独立CD重置；机制结束恢复普通四种怪物。
- 预警结束后起点立即变岩浆块，每2秒前进一个坐标。玩家站在血液最前端的当前岩浆块上连续1秒（前端移动时重新计时），承受30物理伤害（受护甲影响，不受炉温增伤）并堵住整条；被动怪物在已注血部分5格内死亡，堵最近的一条。血液前端持续显示红色光圈和末地烛亮粒子；堵塞成功后立即还原整条血管的建筑原貌。每成功堵住一条炉温降低3%，两种方式均向全队发送成功消息并播放提示音。
- 每条抵达终点加5%炉温，并造成全场基础15物理。所有血管堵塞或抵达终点后结束，恢复全部原方块。
- 血脉使用原生连续BossBar，每堵住一条进度增加1/7，标题显示“熔岩血脉：已堵数量/7”。沿用已有Mod接口，无需为此更换客户端Mod。
- 普通波次按实时1～5人刷5/6/6/7/8只，保留四种怪物，每种最多2只，由 `DungeonMobRegistry -> Huomo.definitions -> MobFactory` 注册生成。近卫/弓卫：350HP、38攻击、45护甲、0.27速度；宠物/灵物：400HP、42攻击、50护甲、0.28速度。宠物史莱姆size=4，死亡不分裂。
- 西北刷怪点 `(1079,15,884)` 相邻残骸挡住大型史莱姆体积；该点保留给其他类型，两只史莱姆随机分配到其余实际宽敞的指定点。
